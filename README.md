## Pedro Pereira

Software developer based in Campinas, Brazil, and Computer Science student (UNIP).

I build small applications, APIs, and data-processing tools, with a focus on input validation and automated tests: making sure a result can be checked against the records that produced it.

### What I work with

- **Languages:** JavaScript, TypeScript, Java, SQL
- **Back end:** Node.js, REST APIs, Spring Boot (study projects)
- **Data:** CSV import and validation, error reporting, aggregations and indicators
- **Testing:** unit tests for parsing and calculation logic; browser checks of user-facing flows

### Featured project

**[`csv-sales-report`](https://github.com/devpedropereira/csv-sales-report)**: a browser-only page that imports a sales CSV, rejects inconsistent rows with a reason (duplicate IDs, impossible dates, invalid amounts), and shows revenue, order count, average order value and a monthly series that can be traced back to the source rows. Plain JavaScript with no dependencies, automated tests in Node.js, and a CSV summary export. Built as a lab project with fictitious data; it has not been used with a client.
